# 369 The Canvas — Art Teacher Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. The uploaded artwork photos are included in `assets/`.

## Preview locally
Open `index.html` in your browser. No build step or dependencies are required.

## Before publishing
1. Replace **369 THE CANVAS** with the artist's preferred name or studio name.
2. Update the email address in the contact section (`hello@example.com`).
3. Review image captions/categories and make any changes you want.
4. Confirm you have permission to publish photos that include students. Consider using artwork-only images or obtaining guardian/school consent before making student photos public.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `art-teacher-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Customize
- Gallery items are in `index.html`; each card has a `data-category`, title, caption and image.
- Supported gallery filters: `painting`, `drawing`, `craft`, `learning`.
- Colors, typography, spacing and responsive breakpoints are in `style.css`.
